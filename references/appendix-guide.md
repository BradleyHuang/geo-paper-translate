# 附录写作指南：公式原理详解 / 论文解读

译本正文之外的**教学附录**写法。用户说「加个附录帮助理解」「解释公式」「论文解读」「讲透这篇论文」「面向学生」时使用。
产出为译本内的 `\section{附录：……}`（放在参考文献之后），不是独立文档。

> **与 `nature-paper-xray` 的边界**：用户要的是**译本里的附录**（"翻译完再加个公式详解/解读"）时用本指南；用户要的是**独立精读文档**（不翻译、单出一份讲透论文的材料）时用 `nature-paper-xray`。同一场景下两者可衔接：先本 skill 出译本，再按本指南补附录。

## 一、两条产品线

| 类型 | 适用 | 核心问题 |
|---|---|---|
| **公式原理详解** | 论文以方法/方程为骨架（解析模型、本构方程、反演公式、相平衡计算） | 每个公式从哪来、怎么读、为什么这么写、有什么用 |
| **论文解读** | 论文论证复杂（多解性、替代假设、证据链长） | 作者为什么这么设计、证据链怎么搭、边界在哪 |

一篇论文可以两者都写（公式部分作小节并入解读），也可以只写其一。短文（<8 页）一个附录 3–5 页为宜；长文按需分节。

## 二、位置与标注（必守）

1. 附录放在**参考文献之后**、`\end{document}` 之前。
2. 首段开宗明义：**「本附录为译者（编者）补充的学习材料……不属于原文内容」**。
3. 首页「说明」段补一句：**「文末附录为译者补充的公式原理详解（或论文解读），面向初学者，不属于原文内容。」**
4. 附录内的图/式引用译本正文的 `\ref`（图 1、式 (4)），**不新增重复图**；确需新图（如标度律示意）才加。
5. 通识标题只写中文：`附录：公式原理详解`、`附录：论文解读`；小节标题口语化、问题化（「这个模型到底在算什么？」优于「模型概述」）。

## 三、公式原理详解：写作框架

以 Davies (1999) 俯冲带热结构解析模型为范本（译本 `Davies-1999-GJI`）：

```text
附录：公式原理详解
├── 这个模型到底在算什么？      # 背景 + 解析 vs 数值（配方 vs 试错）
├── 看懂公式之前：坐标系与几个关键参数  # 配合图 1；每个符号给"是什么、谁定的、典型值"
├── 公式 (1)：……（问题式小标题）   # 边界条件/输入
├── 公式 (2)：……                # 控制方程：逐项白话
├── 公式 (3)：……                # 化简：列出假设 + 比喻
├── 公式 (4)：……                # 一般解：读法 + 直觉图像
├── 公式 (5)：……                # 闭式解：特殊函数是什么 + 自洽检验
├── 三个要记住的推论            # 标度律、无量纲坍缩、已知盲区
├── 这个模型在地质学上有什么用？  # 联系岩浆/变质/地震/观测 + 实际应用
└── 小词典                      # 术语表兜底
```

各环节要点：

- **背景先行**：先回答"算什么、为什么算、有哪两条路"，再进公式。解析 vs 数值的对比（快/透明 vs 灵活/慢）几乎总值得写。
- **符号清单**：列出全部符号，给出地质含义与典型值（$k\approx10^{-6}\,\mathrm{m^2\,s^{-1}}$、$v=1$–$10\ \mathrm{cm\,yr^{-1}}$）。
- **逐式四问**：①物理含义（白话）②来历（守恒律/几何/经验？）③读法（哪项管什么）④代价与假设。
- **比喻库**（直觉优先于推导）：
  - 平流–扩散 → 「传送带上运墨水：沿路运输、横向渗漏」
  - 高斯卷积 → 「给温度剖面加高斯模糊；新温度=邻居加权平均」
  - 误差函数 → 「正态分布的累积面积；台阶被抹成斜坡的抹开程度」
  - 能量守恒 → 「记账：进来的 − 带走的 = 渗进来的 + 自己生的」
  - 无量纲距离 → 「离拐点多远，以模糊宽度为单位」
- **自洽性检验**：挑一个极限（如 $y\to0$ 退回初始条件、量纲核对）演示"解没走样"，显著提升可信度。
- **推论落地**：把数学结构翻译成地质结论（如 $\sqrt{y}$ 增厚律 → 温度随深度格局；$(ky/v)^{1/2}$ 坍缩 → 一张图换尺子涵盖所有参数）。
- **盲区要诚实**：明确模型刻画不了什么（如楔角），并指出原文对应证据（图 5(c) 与 5(a) 差异最大处）。
- **用途收尾**：温度→岩浆/变质/流变/地震/观测检验；点名实际应用（如 Rhodes 1998 全球模拟）。
- **小词典**：8–12 条术语两列表格（booktabs、`\small`、`p{0.24\textwidth}p{0.68\textwidth}`），兜底解析解/数值解/稳态/位温/无量纲等。

### 数值模拟类论文的「模拟详解」模式（Knight-2025-TECT 验证）

地球动力学/热–力学模拟论文（Underworld2、ASPECT、I2VIS/LaMEM 等）用户常说「模拟详解」，套用公式详解框架但内容换成数值模型：

- **三本账开场**：力的账（力平衡/动量守恒，惯性可忽略）、热的账（同解析论文的「记账」比喻）、物质的账（材料标签随流动搬运）；求解方式=欧拉网格+拉格朗日粒子（「面团里嵌芝麻」）。
- **本构公式逐项比喻**：蠕变律 → 阿伦尼乌斯项=「加热=软化」、应变速率依赖 $n>1$=「快流动变稀」；屈服准则 → 「围压越大越难断」；应变弱化 → 「越滑越弱、断层自我聚焦」；$\min$ 组合 → 「绳子最弱一环」→ 脆–韧性转换。
- **数值设置逐问答「为什么」**：CFL（步长红线：物质每步不得越过一个网格）、忽略弹性（百万年尺度早松弛）、sticky air（地形自由演化）、开放底边界（软流圈补偿）、预存弱带（新俯冲沿老薄弱带启动）、**控制变量法**（两侧同岩石=速度当主角，是解读全文实验设计的钥匙）。
- **阈值类结论点明「涌现性」**：临界速率/临界厚度不是输入参数，是模型「长出来」的——这是模拟论文最反直觉也最重要的认识。
- **没模拟的物理列为诚实边界**：熔融、流体、榴辉岩化、弹性等未纳入项，照原文声明（「不暗示也不要求」）转述。
- **小词典增补数值词条**：有限元、拉格朗日粒子、粘度、位错蠕变、扩散蠕变、Drucker–Prager、脆–韧性转换、CFL、端元、粘性空气层等。
- **解读侧重点**：与解析论文不同，模拟论文的解读重心常在**实验设计**（端元对照+敏感性+真实历史三线并行）与**判别性对照**（如 D=0 排除侵蚀假说）——放在「作者为什么这么设计」与「替代解释排除」两节。

## 四、论文解读：写作框架

```text
附录：论文解读
├── 一句话说清这篇论文在回答什么    # 30 秒版本
├── 作者为什么这么设计              # 约束、可选项、被否掉的路线
├── 证据链拆解                      # 假设 → 方法 → 结果 → 结论，逐环标注强度
├── 关键图表怎么读                  # 不复述数据，教"看哪里、怎么判断"
├── 替代解释与作者如何排除          # 多解性；对照实验/限定词（may/suggest）
├── 边界与局限                      # 假设失效处、适用范围、未回答的问题
├── 这项工作改变了什么              # 与前人（被引文献）的关系、后续应用
└── 小词典 / 延伸阅读
```

要点：

- **区分证据与推断**：观察/实验结果 vs 模型输出 vs 作者解读，三层分开写；保留 may / suggest / inferred 的语气。
- **讲取舍不讲流水账**：「为什么用 X 而不用 Y」比「作者做了 A、B、C」有价值。
- **多解性是金矿**：同一观测的替代解释、作者用什么判据排除，这是学生最缺的训练。
- **图表解读**：教"第一眼看哪条线、哪个区、什么形态算支持假设"。

## 五、文风准则（面向数学/数值基础弱的学生）

1. **先比喻后公式**：一句话直觉 → 公式 → 逐项拆解；禁止一上来就推导。
2. **每个符号先安顿**：第一次出现即给含义与量级，不让学生猜 $d$ 是什么。
3. **不省略"为什么敢"**：每条假设都给合理性（"倾向梯度远小于横向梯度，因为……"）。
4. **短段落 + 列表**：一项一段；长句拆短；多用 `itemize`/`enumerate`。
5. **口语化标题**：问题式（「误差函数是什么？」「这个模型有什么用？」）。
6. **弯引号**：中文引号用 `“”`；**禁止 ASCII `"`**（XeLaTeX 渲染成两个右引号）。替换脚本按行配对转、跳过 `\"`（TeX 重音，如 `Toks\"{o}z`）。
7. **不装严谨**：附录是教学材料，允许类比与简化；但**不得与正文/原文矛盾**，简化处注明"此处为直观说法"。

## 六、LaTeX 要点

```latex
\section{附录：公式原理详解}
\noindent（本附录为译者补充的学习材料，意在帮助数学与数值基础较弱的同学
理解文中公式 (1)–(5) 的来历、读法与用途，不属于原文内容。）
```

- 复刻正文公式用 `equation*`（不与正文 (1)–(5) 抢编号），讲解里引用正文编号。
- 逐项注释用 `\underbrace{...}_{\text{白话注释}}`（amsmath）。
- 引用正文：`图~\ref{fig:fig01}`、`式~(4)`、`公式 (1a)`。
- 小词典：booktabs 表格浮动用 `[!htb]`。
- 附录会自动进目录；编译两遍稳定页码。

## 七、验收追加项

在 SKILL.md 验收清单之外：

1. **标注**：附录首段 + 首页「说明」均有"非原文内容"声明。
2. **引用可达**：附录里所有 `\ref` 指向正文已有图/式；无悬空引用。
3. **公式复刻正确**：附录中的公式与正文逐符号一致（上标、下标、根号、积分限）。
4. **弯引号**：全文 ASCII `"` 残留 = 0（排除 `\"` 重音行）。
5. **术语残留**照常为 0；附录不得引入「建模/赝剖面」等禁用译名。
6. **量纲与极限**：若写了自洽检验，核对其结论正确（如 $y\to0$ 退化）。
